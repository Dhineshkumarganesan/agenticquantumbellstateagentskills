# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it by emailing Dhineshkumarganesan or opening a private issue. Do not disclose security issues publicly until they have been reviewed and addressed.

We will respond as quickly as possible and keep you informed of the progress.

## Supported Versions

We currently support the latest major version. Older versions may not receive security updates.

Thank you for helping keep this project and its users safe!
